Producto: PushGo

Correo de soporte: [support@pushgo.dev](mailto:support@pushgo.dev)

El soporte de PushGo cubre los clientes publicados para plataformas Apple, el cliente Android y preguntas de configuración de Gateway. Para solicitudes de soporte de App Store sobre iOS, macOS o watchOS, use el correo indicado arriba.

## Cómo obtener ayuda

Si tiene problemas como notificaciones que no llegan, fallos de suscripción, mensajes que no se sincronizan, errores de conexión Gateway o comportamiento inesperado, contáctenos en [support@pushgo.dev](mailto:support@pushgo.dev).

## Qué incluir

- Modelo del dispositivo y versión del sistema operativo.
- Versión de la app PushGo.
- Plataforma: iOS, macOS, watchOS, Android o Gateway.
- Endpoint Gateway o tipo de despliegue, si es relevante.
- Contexto de Channel, por ejemplo si usa Gateway público o Gateway autoalojado.
- Cuándo ocurrió el problema, qué observó y si se puede reproducir.
- Capturas, logs o mensajes de error que ayuden a describir el problema.

No envíe contraseñas de Channel, tokens de acceso, claves privadas u otros secretos por correo.

## Preguntas frecuentes

### No recibo notificaciones. ¿Qué debo revisar primero?

Confirme que el permiso de notificaciones del sistema está activado y revise la dirección Gateway, las credenciales de Channel, el estado de red, los modos de concentración y el estado del servicio push de la plataforma.

### ¿Qué información ayuda con problemas de sincronización?

Indique la plataforma, si el problema afecta a uno o varios dispositivos, y si usa Gateway público o Gateway autoalojado.

### ¿Debo incluir logs?

Los logs básicos o mensajes de error son útiles si no contienen secretos. Elimine contraseñas de Channel, tokens, claves privadas y contenido personal antes de compartirlos.

### ¿Cómo se distribuyen las actualizaciones?

Las actualizaciones para plataformas Apple se distribuyen por App Store. Las versiones Android y los builds Gateway se distribuyen por sus canales públicos de release.

## Privacidad y datos

PushGo no usa solicitudes de soporte para publicidad ni perfiles de comportamiento. La información que usted envía al soporte se usa para entender, diagnosticar y resolver el problema reportado.
