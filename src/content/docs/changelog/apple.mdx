## v1.3.0
*2026-08-23*

### Improved
- Pulled deliveries are acknowledged only after safe local persistence, using grouped ACK batches with beta-Gateway compatibility.
- Added widgets and controls, system search indexing, App Shortcuts, and WidgetKit push updates across iPhone, Mac, and Apple Watch.
- Reworked the Apple Watch receiver, improved cached images and localization, and added automatic retry for persisted notification ingestion.
- Background work now reports completion accurately, with durable retry and safer upgrade/rollback state.

### Fixed
- Fixed notification-open navigation, background completion, and delayed local visibility edge cases.

## v1.2.7
*2026-06-15*

### Improved
- Refined selectable Markdown detail rendering on iOS and macOS and added a watchOS-specific plain-text detail path.

## v1.2.6
*2026-06-12*

### Fixed
- Fixed iOS message-detail text-selection crashes and made selectable Markdown text consistent on macOS.

## v1.2.5
*2026-06-09*

### Improved
- Lowered requirements to iOS 17, macOS 14, and watchOS 10; added customizable notification sounds and improved entity patch projection.

### Fixed
- Fixed compatibility and state-sync regressions found while lowering deployment targets.

## v1.2.4
*2026-05-26*

### Improved
- Improved cross-platform interaction consistency for message, event, and thing lists between iOS and macOS.
- Improved toast and inline feedback clarity across settings, search, and management surfaces.
- Shared app controllers now reduce iOS/macOS behavior drift in channel sync and notification ingress flows.
- Improved local data and automation runtime stability under retry and larger-state conditions.

## v1.2.3
*2026-05-16*

### Improved
- The unread-only message filter now stays active when returning to the message list.
- Channel subscription lists are more stable and reject blank or duplicate subscription identifiers.
- Large rich-text and Markdown message details render more smoothly.
- Notification taps open message details more reliably before read-state refresh finishes.
- Filtering remains usable with larger tag sets and heavier local message data.

## v1.2.2
*2026-05-11*

### Improved
- Added tag-aware message search and multi-select facet filters with tag counts.
- Improved list filtering and discovery across messages, events, and objects.
- Unified destructive delete/close actions with undoable local deletion behavior.
- Improved error feedback consistency across iOS, macOS, and watchOS.
- Hardened notification ingress recovery and Apple Watch delivery reliability.

## v1.2.1
*2026-04-24*

### Improved
- Included Apple-side reliability updates accumulated after v1.2.0.
- Improved overall reliability and behavior consistency across iOS, macOS, and watchOS.
- Improved Markdown and remote image rendering stability in shared Apple UI surfaces.

## v1.2.0
*2026-04-20*

### Improved
- Improved ACK + pull reliability after provider token refresh by triggering ingress sync immediately.
- Improved delivery continuity on iOS and macOS when provider route bindings refresh.

### Fixed
- Fixed a timing gap where provider pull could lag behind token updates.
