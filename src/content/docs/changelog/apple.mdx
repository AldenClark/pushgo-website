## v1.3.3

### Improved
- Search and message loading show clearer progress and retry feedback on iPhone and Mac.
- The Mac status item restores the main window more reliably.

### Fixed
- On iPhone, opening message filters after marking a selected scope as read no longer crashes the app.
- Refreshing message content preserves the user's local read or unread state.
- Expired provider acknowledgement leases can be reclaimed so interrupted notification processing can resume.
- Deliveries from different Gateways remain separate even when they share a delivery identifier.
- Changing Gateways validates the replacement before switching and keeps the save result visible.
- Opening an unavailable object on Mac no longer shows an unrelated object's detail.
- Rich message images no longer retain stale attachments or stop a restarted animation.
- Message history can recover when an app upgrade is interrupted while moving its database.
- On smaller Mac displays, the Undo button remains visible and clickable while a message deletion is pending.
- Apple Watch cleans up the old push route after a Gateway or receiver-mode change, resumes interrupted cleanup, and registers again when returning to an earlier Gateway.
- Apple Watch waits for a complete iPhone settings sync before using updated receiver settings.

## v1.3.0
*2026-08-23*

### Improved
- Pulled deliveries are acknowledged only after safe local persistence, using grouped ACK batches with beta-Gateway compatibility.
- Added widgets and controls, system search indexing, App Shortcuts, and WidgetKit push updates across iPhone, Mac, and Apple Watch.
- Reworked the Apple Watch receiver, improved cached images and localization, and added automatic retry for persisted notification ingestion.
- Background work now reports completion accurately, with durable retry and safer upgrade/rollback state.

### Fixed
- Fixed notification-open navigation, background completion, and delayed local visibility edge cases.
