description: PushGo iOS、macOS、watchOS アプリのバージョン履歴。

## v1.2.4
*2026-05-26*

### 改善
- iOS と macOS 間で Message、Event、Thing リストの操作一貫性を改善しました。
- 設定、検索、管理画面での toast とインラインフィードバックの明瞭さを改善しました。
- 共有アプリコントローラーにより、Channel 同期と通知取り込みフローにおける iOS/macOS の挙動差を減らしました。
- 再試行や大きなローカル状態の条件下で、ローカルデータと自動化ランタイムの安定性を改善しました。

## v1.2.3
*2026-05-16*

### 改善
- メッセージ一覧へ戻ったとき、未読のみフィルターが有効なままになります。
- Channel サブスクリプション一覧の安定性を高め、空または重複したサブスクリプション識別子を拒否します。
- 大きなリッチテキストや Markdown メッセージ詳細の描画がより滑らかになりました。
- 通知タップ時に、既読状態更新の完了前でもメッセージ詳細をより確実に開きます。
- 大きなタグ集合や重いローカルメッセージデータでもフィルターを使いやすくしました。

## v1.2.2
*2026-05-11*

### 改善されました
- タグ対応Message検索とタグ数による複数選択ファセット フィルターを追加しました。
- Message、Event、オブジェクトにわたるリストのフィルタリングと検出が改善されました。
- 取り消し可能なローカル削除動作を備えた統合された破壊的な削除/閉じるアクション。
- iOS、macOS、watchOS 間でのエラー フィードバックの一貫性が向上しました。
- 強化された通知受信リカバリと Apple Watch 配信の信頼性。

## v1.2.1
*2026-04-24*

### 改善されました
- v1.2.0 以降に蓄積された Apple 側の信頼性アップデートが含まれています。
- iOS、macOS、watchOS 全体の信頼性と動作の一貫性が向上しました。
- 共有 Apple UI サーフェスでの Markdown とリモート イメージ レンダリングの安定性が向上しました。

## v1.2.0
*2026-04-20*

### 改善されました
- 入力同期を即座にトリガーすることで、プロバイダー トークンの更新後の ACK + プルの信頼性が向上しました。
- プロバイダーのルート バインディングが更新されるときの iOS および macOS での配信の継続性が向上しました。

### 修正済み
- プロバイダーのプルがトークンの更新に遅れる可能性があるタイミング ギャップを修正しました。
