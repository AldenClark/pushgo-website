製品：PushGo

サポートメール：[support@pushgo.dev](mailto:support@pushgo.dev)

PushGo のサポートは、公開済みの Apple プラットフォーム向けクライアント、Android クライアント、Gateway 設定に関する質問を対象とします。App Store の iOS、macOS、watchOS 版に関する技術サポートは、上記メールアドレスへご連絡ください。

## サポートへの連絡方法

通知が届かない、購読に失敗する、メッセージが同期されない、Gateway に接続できない、または予期しない動作がある場合は、[support@pushgo.dev](mailto:support@pushgo.dev) までご連絡ください。

## 記載してほしい情報

- デバイスモデルと OS バージョン。
- PushGo アプリのバージョン。
- 利用プラットフォーム：iOS、macOS、watchOS、Android、または Gateway。
- 関連する場合は Gateway エンドポイントまたはデプロイ方式。
- Channel 設定の背景。公共 Gateway かセルフホスト Gateway かなど。
- 問題が発生した時刻、実際の現象、再現性。
- 問題説明に役立つスクリーンショット、ログ、エラーメッセージ。

Channel パスワード、アクセストークン、秘密鍵、その他の機密情報はメールで送らないでください。

## よくある質問

### 通知が届かない場合、最初に何を確認すべきですか？

まずシステムの通知権限が有効か確認し、その後 Gateway アドレス、Channel 認証情報、ネットワーク状態、集中モード、プラットフォームのプッシュ配信状態を確認してください。

### 購読やメッセージ同期の問題では、どの情報が役立ちますか？

利用プラットフォーム、問題が 1 台のデバイスだけか複数デバイスで起きるか、公共 Gateway かセルフホスト Gateway かをお知らせください。

### ログを添付すべきですか？

機密情報を含まない基本的なログやエラーメッセージは役立ちます。共有前に Channel パスワード、トークン、秘密鍵、個人情報を削除してください。

### アプリの更新はどこから入手できますか？

Apple プラットフォームの更新は App Store から配信されます。Android 版と Gateway ビルドは、それぞれの公開リリースチャンネルから配信されます。

## プライバシーとデータ

PushGo はサポートリクエストを広告や行動プロファイリングに使用しません。サポートに送信された情報は、報告された問題の理解、調査、解決のために使用されます。
