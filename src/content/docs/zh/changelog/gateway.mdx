## v1.3.3

### 改进
- SQLite、PostgreSQL 和 MySQL 的路由切换均采用可恢复的原子事务，也支持 PostgreSQL 和 MySQL 部署上的 Android 手动传输切换。
- 路由恢复可通过当前 provider token 的 SHA-256 指纹核对状态，而不暴露 token 本身。

### 修复
- FCM 或 WNS 拒绝已缓存的 provider token 后，Gateway 会请求 Token Service 强制刷新，再重试投递。此恢复能力需要更新 Token Service。
- 设备接管 provider token，或订阅、退役与路由切换并发时，token 归属和投递路由保持一致。
- 路由删除无法持久化时，待投递的私有消息仍会保留。
- 已完成的路由切换在过期或后续切换后仍可安全重试；失败的重试不会让内存中的活动路由出错。
- 多字节 provider token 不再导致诊断日志崩溃。
- 私有 TCP 连接收到分片帧时，即使出站投递打断读取，也能继续正确读取该帧。
- MySQL 上的私有设备活跃状态更新和退订清理恢复正常，设备退订或更换身份后仍能正确处理。

## v1.3.1
*2026-08-24*

### 修复
- 恢复对接受无鉴权 HTTPS 请求的 token service 的兼容性；Gateway API 的访问 token 行为未变。

## v1.3.0
*2026-08-23*

### 改进
- 新增非破坏性分页 Pull v2 与持久原子批量 ACK；破坏性旧路由仅保留用于 beta 兼容。
- 新增 MQTT 5 私有传输和持久 QoS 1 重连，并使私有/provider 路由切换保持原子性。
- 新增绑定 Message payload 的 `op_id` 幂等、发送状态和前向兼容请求解析，同时继续拒绝动作禁止字段。
- 规范 APNs/FCM/WNS token，修正 APNs 过期时间，并把 provider 成功状态移动到真实发送完成之后。
- Widget 与 Live Activity 最新状态投递在重启和恢复期间保持持久、有序且不会倒退过期时间。
- 强化受管数据库升级并确立 schema v12 回滚边界。

## v1.2.10
*2026-06-10*

### 改进
- 拆分 Event/Thing 生命周期请求结构，使每个动作只接受有效字段，避免跨模型携带无关 patch 数据。

## v1.2.9
*2026-05-26*

### 改进
- 改进提供商凭据刷新可靠性：定向重试路径会强制重新拉取 token-provider 信息，常规投递仍优先使用缓存以降低延迟。
- 新增明确的运行时档位选择：`small` 仍是私有或轻量部署默认值，`public` 用于高负载部署。
- 将队列、分发、提供商、数据库连接池和 SQLite 等底层调优收敛为档位内置默认值，降低误配置风险。
- 在统计写入失败后限制保留行数，避免临时存储压力导致内存无界增长。

## v1.2.8
*2026-05-13*

### 改进
- 提高了高负载消息分发稳定性，修复 pending dedupe 清理时间窗口计算问题，避免慢速 fanout 写入期间出现间歇性失败。
- 增加明确的单频道 32 个订阅者限制响应，包含结构化错误码和本地化消息，便于客户端可预期处理满员频道。
- 增加可复现的容量基准测试工具，方便后续做网关容量回归检查。

## v1.2.7
*2026-05-10*

### 改进
- 强化 SQLite、PostgreSQL 和 MySQL 的升级可靠性验证，覆盖旧运行时迁移、schema 收敛和升级后读写行为。
- 完成发布前 preflight、blackbox 和跨数据库一致性审计，提升生产发布可信度。

## v1.2.5
*2026-04-22*

### 修复
- 修复部分 SQLite 环境中私有维护清理失败的问题，避免依赖并非所有 SQLite 构建都支持的 `DELETE ... LIMIT` 语法。

### 改进
- 当 `PUSHGO_PUBLIC_BASE_URL` 包含自定义端口时，私有传输 profile 会正确宣告 `wss_port`，让客户端使用一致的外部入口。

## v1.2.4
*2026-04-22*

### 改进
- 私有通道配置改为显式 `PUSHGO_PRIVATE_TRANSPORTS` / `--private-transports`，支持 `none`、`wss`、`quic,tcp,wss` 等明确组合。
- 运行时严格遵循选中的传输：只有启用 `wss` 才挂载 `/private/ws`，只有启用 QUIC/TCP 才启动对应监听。
- TLS 依赖检查按传输类型区分：QUIC 必须配置证书和私钥；TCP 只在未 TLS offload 时需要；WSS 不需要私有通道证书。
