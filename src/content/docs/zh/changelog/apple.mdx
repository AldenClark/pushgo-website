## v1.2.4
*2026-05-26*

### 改进
- 改进 iOS 与 macOS 之间 Message、Event、Thing 列表的跨平台交互一致性。
- 改进设置、搜索和管理界面的 toast 与内联反馈清晰度。
- 共享应用控制器减少了 iOS/macOS 在 Channel 同步和通知入口流程中的行为漂移。
- 提升重试和较大本地状态条件下的本地数据与自动化运行稳定性。

## v1.2.3
*2026-05-16*

### 改进
- 返回消息列表时，“只看未读”过滤状态会继续保持。
- Channel 订阅列表更稳定，并会拒绝空白或重复的订阅标识。
- 大型富文本和 Markdown 消息详情渲染更流畅。
- 点击通知后会更可靠地先打开消息详情，再完成已读状态刷新。
- 在更大的标签集合和更重的本地消息数据下，过滤仍保持可用。

## v1.2.2
*2026-05-11*

### 改进
- 新增基于标签的消息搜索和带数量提示的多选 facet 筛选。
- 改进消息、事件和实体列表筛选与发现体验。
- 删除和关闭等破坏性操作统一为可撤销的本地删除行为。
- 改进 iOS、macOS 和 watchOS 的错误反馈一致性。
- 加强通知接入恢复和 Apple Watch 投递可靠性。

## v1.2.1
*2026-04-24*

### 改进
- 汇总 v1.2.0 之后的 Apple 侧稳定性更新。
- 改进 iOS、macOS 和 watchOS 的整体可靠性与行为一致性。
- 改进共享 Apple UI 中 Markdown 和远程图片渲染稳定性。

## v1.2.0
*2026-04-20*

### 改进
- 通过在提供商令牌刷新后立即触发接入同步，提高 ACK + pull 的可靠性。
- 改进 iOS 和 macOS 在提供商路由绑定刷新时的交付连续性。

### 修复
- 修复提供商拉取可能滞后于令牌更新的时间差。
