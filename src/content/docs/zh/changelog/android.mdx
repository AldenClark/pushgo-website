## v1.3.3

### 修复
- 修复过期的后台状态事件让本地删除的撤销提前结束的问题；撤销请求按五秒截止时间严格判定。
- Gateway 编辑保存失败时保留已输入内容，受保护设置写入错误会明确提示用户。
- 在较小屏幕或键盘打开时，Gateway、Channel 编辑器和历史清理选项可滚动，保存按钮与末端选项仍可操作。
- 数据页面选项可横向滚动，窄屏下仍可调整每个页面设置。
- 筛选或读状态变化后列表不足以滚动时，底部导航会恢复显示。
- 搜索耗时较长时显示进度。
- 从搜索结果打开消息时会收起键盘，使返回操作能正常关闭详情。
- Channel 重新订阅和同步时保留已有别名或名称。
- 传输切换已由 Gateway 提交、但设备本地处理被中断时，App 会继续恢复，并在设置中显示恢复中的状态。
- 从消息打开外部网页再返回时，会保留原消息详情。
- 图片地址会拦截 IPv4 映射形式的本地或私有地址。
- 分享消息图片时，系统分享面板现在可显示预览，选定的应用也可读取图片。

## v1.3.0
*2026-08-24*

### 改进
- 新增非破坏性分页 Pull 和批量 ACK，并兼容 beta Gateway；旧版破坏性 Pull 与 v2 保持隔离。
- 拉取通知和待处理本地删除会保留到持久处理成功，中断或进程重启后可继续。
- 扩展实体搜索与筛选，增加站内指南入口，并改进文档行的无障碍语义。
- 持久通知恢复不会重新播放系统或自定义提示音。

### 修复
- ACK 保持绑定到产生它的 Gateway，使用外层权威 delivery ID，并仅在结构完整的全量确认后删除。
- 修复 Gateway 切换、Pull 中断、provider 接入串行化和重试导致的待处理任务丢失或错投问题。

## v1.2.6
*2026-06-09*

### 改进
- 最低支持降到 Android 9，并改进实体投影、当前可见范围的全部已读和待删除刷新。

### 修复
- 修复 Android 9 兼容性和 patch 更新后的 Event/Thing 详情陈旧问题。

## v1.2.5
*2026-05-26*

### 改进
- 打开消息详情时，改进详情底部弹层的稳定性和展示一致性。
- 改进图片加载失败处理，在消息详情和 Markdown 内容中提供更清晰的占位和本地化失败文案。

## v1.2.4
*2026-05-18*

### 改进
- 改进“只看未读”消息过滤连续性：应用重启后仍会保留未读过滤偏好。
- 当私有 Channel 达到订阅者上限时，改进 gateway/channel 错误说明，并在应用内给出直接可执行的指引。

### 修复
- 修复私有 Channel 订阅者上限错误被归类为通用校验失败的问题，避免根因诊断不清。

## v1.2.3
*2026-05-11*

### 改进
- 删除流程升级为可撤销机制，误删后更容易恢复。
- 消息列表新增“将当前显示内容全部标记为已读”操作，提高批量处理效率。
- 消息筛选改进为更清晰的多选 facet 控件，并与标签搜索保持一致。
- 改进消息接收可靠性和应用内消息状态一致性。

### 修复
- 修复 Markdown 和详情页中动图识别与播放问题。
- 修复详情页媒体加载阻塞界面响应的问题。

## v1.2.2
*2026-04-24*

### 改进
- 改进加密通知载荷处理，解密后的消息、链接、图片以及事件/实体 metadata 在不同页面保持一致。
- 消息、事件和实体界面增加更清晰的频道与解密状态提示。
- 详情页图片加载和点击行为增加明确的加载/错误占位，并降低媒体未就绪时的误触风险。

## v1.2.1
*2026-04-22*

### 改进
- 应用启动期间的入站消息会排队并重试，减少早期运行阶段消息丢失。
- 改进入站路由和重复抑制逻辑，提升私有通道与厂商通道的一致性。
- 改进设置页和消息详情页状态更新，失败反馈更清晰。
- 改进事件和实体页面的详情同步、分页以及关闭/删除交互。

## v1.2.0
*2026-04-20*

### 修复
- 修复 Android 更新安装被阻止时缺少即时应用内错误提示的问题。
- 修复安装被阻止后的回退流程，用户可以继续通过 Android 系统安装程序完成安装。

### 改进
- 改进应用内更新失败后的连续性和恢复路径。
