产品：PushGo

支持邮箱：[support@pushgo.dev](mailto:support@pushgo.dev)

PushGo 技术支持覆盖已发布的 Apple 平台客户端、Android 客户端，以及 Gateway 相关配置问题。App Store 中 iOS、macOS 或 watchOS 版本的技术支持请求，请通过上方邮箱联系我们。

## 如何联系支持

如果你遇到收不到通知、订阅失败、消息不同步、Gateway 连接错误或其他异常行为，请发送邮件至 [support@pushgo.dev](mailto:support@pushgo.dev)。

## 建议附带的信息

- 设备型号和操作系统版本。
- PushGo App 版本号。
- 使用平台：iOS、macOS、watchOS、Android 或 Gateway。
- 如与 Gateway 有关，请说明 Gateway 地址或部署方式。
- Channel 配置背景，例如使用公共 Gateway 还是私有部署 Gateway。
- 问题发生时间、实际现象，以及是否可以稳定复现。
- 有助于说明问题的截图、日志或错误提示。

请不要通过邮件发送 Channel 密码、访问令牌、私钥或其他敏感凭据。

## 常见问题

### 收不到通知时应该先检查什么？

请先确认系统通知权限已经开启，再检查 Gateway 地址、Channel 凭据、网络状态、专注模式，以及平台推送服务状态。

### 订阅或消息不同步时，哪些信息最有用？

请说明使用的平台、问题是只影响一台设备还是多台设备，以及你使用的是公共 Gateway 还是私有部署 Gateway。

### 是否应该附带日志？

不包含敏感信息的基础日志或错误提示通常很有帮助。分享日志前，请移除 Channel 密码、令牌、私钥和个人内容。

### App 如何更新？

Apple 平台版本通过 App Store 分发。Android 版本和 Gateway 构建通过各自公开的发布渠道分发。

## 隐私与数据

PushGo 不会将技术支持请求用于广告或行为画像。你主动发送给技术支持的信息仅用于理解、排查和解决你报告的问题。
