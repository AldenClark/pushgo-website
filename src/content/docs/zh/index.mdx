## 为什么选择 PushGo

<CardGrid stagger>
  <Card title="三类数据模型" icon="document">
    Message 处理一次性提醒，Event 跟踪可多次更新的生命周期，Thing 维护设备、服务或任务的当前状态。
  </Card>
  <Card title="平台原生投递" icon="rocket">
    Apple 客户端通过 APNs 接收系统通知，Android 客户端可结合 FCM 和私有通道获得更灵活的同步能力。
  </Card>
  <Card title="可私有部署" icon="setting">
    Gateway 可运行在自己的服务器上，支持持久化数据库、网关级鉴权、私有通道、可观测性和反向代理部署。
  </Card>
  <Card title="端到端加密字段" icon="heart">
    敏感展示字段可以放入 `ciphertext`，由客户端本地解密，Gateway 只负责透传、鉴权和分发。
  </Card>
  <Card title="迁移成本低" icon="star">
    兼容 ntfy、Bark 和 ServerChan 入口，适合先迁移现有脚本，再逐步升级到原生数据模型。
  </Card>
  <Card title="MCP/OAuth" icon="random">
    Gateway 可作为 MCP HTTP Server，让 AI 助手在用户授权频道范围内发送 Message、管理 Event 和更新 Thing。
  </Card>
</CardGrid>

## 最小请求示例

```bash
curl -X POST https://gateway.pushgo.cn/message \
  -H "Content-Type: application/json" \
  -d '{
    "channel_id": "YOUR_CHANNEL_ID",
    "password": "YOUR_CHANNEL_PASSWORD",
    "title": "来自 PushGo 的问候",
    "body": "这是一条测试通知。"
  }'
```
