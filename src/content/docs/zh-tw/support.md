產品：PushGo

支援信箱：[support@pushgo.dev](mailto:support@pushgo.dev)

PushGo 技術支援涵蓋已發佈的 Apple 平台用戶端、Android 用戶端，以及 Gateway 相關設定問題。App Store 中 iOS、macOS 或 watchOS 版本的技術支援請求，請透過上方信箱聯絡我們。

## 如何聯絡支援

如果你遇到收不到通知、訂閱失敗、訊息不同步、Gateway 連線錯誤或其他異常行為，請寄信至 [support@pushgo.dev](mailto:support@pushgo.dev)。

## 建議附帶的資訊

- 裝置型號和作業系統版本。
- PushGo App 版本號。
- 使用平台：iOS、macOS、watchOS、Android 或 Gateway。
- 如與 Gateway 有關，請說明 Gateway 位址或部署方式。
- Channel 設定背景，例如使用公共 Gateway 還是私人部署 Gateway。
- 問題發生時間、實際現象，以及是否可以穩定重現。
- 有助於說明問題的截圖、日誌或錯誤提示。

請不要透過電子郵件傳送 Channel 密碼、存取權杖、私鑰或其他敏感憑據。

## 常見問題

### 收不到通知時應該先檢查什麼？

請先確認系統通知權限已經開啟，再檢查 Gateway 位址、Channel 憑據、網路狀態、專注模式，以及平台推播服務狀態。

### 訂閱或訊息不同步時，哪些資訊最有用？

請說明使用的平台、問題是只影響一台裝置還是多台裝置，以及你使用的是公共 Gateway 還是私人部署 Gateway。

### 是否應該附帶日誌？

不包含敏感資訊的基礎日誌或錯誤提示通常很有幫助。分享日誌前，請移除 Channel 密碼、權杖、私鑰和個人內容。

### App 如何更新？

Apple 平台版本透過 App Store 分發。Android 版本和 Gateway 建置透過各自公開的發佈渠道分發。

## 隱私與資料

PushGo 不會將技術支援請求用於廣告或行為分析。你主動傳送給技術支援的資訊僅用於理解、排查和解決你回報的問題。
