## v1.3.3

### 改進
- iPhone 和 Mac 的搜尋與訊息載入提供更清楚的進度和重試回饋。
- Mac 選單列圖示可更可靠地恢復主視窗。

### 修復
- 重新整理訊息內容時保留使用者在本機設定的已讀或未讀狀態。
- 已到期的 provider ACK 租約可重新領取，讓中斷的通知處理繼續進行。
- 不同 Gateway 的投遞即使使用相同 delivery ID，也會分別保留。
- 切換 Gateway 前會驗證替代位址，並保留清楚的儲存結果回饋。
- 在 Mac 上開啟無法使用的物件時，不再顯示其他物件的詳情。
- 富文字訊息圖片不再保留過期附件，重新播放的動畫也不會被舊計時器停止。
- App 升級期間搬移資料庫若被中斷，歷史訊息仍可恢復。
- 在較小的 Mac 螢幕上，訊息等待刪除期間，「復原」按鈕仍可看見並點選。
- Apple Watch 切換 Gateway 或接收模式後會清理舊推播路由；清理中斷後繼續執行，返回舊 Gateway 時重新註冊。
- Apple Watch 會等待 iPhone 設定完整同步後，再使用更新的接收設定。

## v1.3.0
*2026-08-23*

### 改進
- 拉取內容僅在安全持久化後確認，並使用分組 ACK 批次相容 beta Gateway。
- 新增小工具與控制項、系統搜尋索引、App Shortcuts，以及涵蓋 iPhone、Mac、Apple Watch 的 WidgetKit 推播更新。
- 重做 Apple Watch 接收端，改善圖片快取和在地化，並為已持久通知接入增加自動重試。
- 背景工作現在會準確回報完成狀態，並保留可恢復工作與安全升級/回滾狀態。

### 修復
- 修復通知開啟導覽、背景完成回報和延遲本機可見性問題。

## v1.2.7
*2026-06-15*

### 改進
- 改善 iOS/macOS 可選取 Markdown 詳情，並為 watchOS 增加專用純文字詳情路徑。

## v1.2.6
*2026-06-12*

### 修復
- 修復 iOS 訊息詳情文字選取當機，並統一 macOS 可選取 Markdown 文字行為。

## v1.2.5
*2026-06-09*

### 改進
- 系統需求降低到 iOS 17、macOS 14、watchOS 10，新增自訂通知聲音並改善實體 patch 投影。

### 修復
- 修復降低部署目標時發現的相容性和狀態同步問題。

## v1.2.4
*2026-05-26*

### 改進
- 改進 iOS 與 macOS 之間 Message、Event、Thing 列表的跨平台互動一致性。
- 改進設定、搜尋與管理介面的 toast 與內嵌回饋清晰度。
- 共享應用控制器減少了 iOS/macOS 在 Channel 同步與通知入口流程中的行為漂移。
- 提升重試與較大本機狀態條件下的本機資料與自動化執行穩定性。

## v1.2.3
*2026-05-16*

### 改進
- 返回訊息列表時，「只看未讀」篩選狀態會繼續保持。
- Channel 訂閱列表更穩定，並會拒絕空白或重複的訂閱識別。
- 大型富文字與 Markdown 訊息詳情渲染更流暢。
- 點擊通知後會更可靠地先開啟訊息詳情，再完成已讀狀態刷新。
- 在更大的標籤集合與更重的本機訊息資料下，篩選仍保持可用。

## v1.2.2
*2026-05-11*

### 改進
- 新增基於標籤的訊息搜尋和帶有數量提示的多重選擇 facet 篩選。
- 改善訊息、事件和實體清單篩選與發現體驗。
- 刪除和關閉等破壞性操作統一為可撤銷的本機刪除行為。
- 改善 iOS、macOS 和 watchOS 的錯誤回饋一致性。
- 加強通知接取恢復和 Apple Watch 投遞可靠性。

## v1.2.1

### 改進
- 匯總 v1.2.0 之後的 Apple 側穩定性更新。

- 改進共享 Apple UI 中 Markdown 和遠端圖片渲染穩定性。

## v1.2.0
*2026-04-20*

### 改進
- 透過在提供者令牌重新整理後立即觸發存取同步，提高 ACK + pull 的可靠性。
- 改進 iOS 和 macOS 在提供者路由繫結重新整理時的交付連續性。

### 修復
- 修復提供者拉取可能滯後於令牌更新的時間差。
