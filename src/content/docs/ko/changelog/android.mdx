## v1.2.3
*2026-05-11*

### 개선됨
- 더 쉬운 복구를 위해 실행 취소할 수 없는 로컬 삭제로 Message 삭제 기능이 향상되었습니다.
- 현재 표시된 모든 Message를 읽음으로 표시하는 작업이 추가되었습니다.
- 태그 검색과 일치하는 보다 명확한 다중 선택 패싯 컨트롤을 통해 Message 필터링이 개선되었습니다.
- Message 수신 안정성 및 인앱 Message 상태 일관성이 향상되었습니다.

### 수정됨
- Markdown/세부 렌더링에서 애니메이션 이미지 감지 및 재생을 수정했습니다.
- 가져오기가 더 이상 화면 응답을 차단하지 않도록 세부 정보 페이지 미디어 로딩을 수정했습니다.

## v1.2.2
*2026-04-24*

### 개선됨
- 암호화된 알림 페이로드 처리가 개선되어 해독된 Message, URL, 이미지 및 Event/객체 메타데이터가 보기 전체에서 일관되게 유지됩니다.
- Message, Event, 객체 화면 전반에 걸쳐 더 명확한 채널 및 암호 해독 상태 표시기를 추가했습니다.
- 명시적인 로드/오류 자리 표시자를 통해 세부 이미지 로드 및 탭 동작이 개선되었습니다.

## v1.2.1
*2026-04-22*

### 개선됨
- 초기 런타임 Message 손실을 줄이기 위해 앱 시작 중에 인바운드 Message를 대기열에 추가하고 재시도했습니다.
- 더 엄격한 라우팅 및 더 안전한 중복 억제를 통해 프라이빗/공급자 수신 일관성이 향상되었습니다.
- 보다 명확한 로드 실패 피드백을 통해 설정 및 Message 세부 정보 상태 업데이트가 개선되었습니다.
- Event 및 객체 세부 정보 동기화, 페이지 매김, 닫기/삭제 상호 작용이 개선되었습니다.

## v1.2.0
*2026-04-20*

### 수정됨
- 사용자가 인앱 오류 알림을 즉시 받을 수 있도록 Android 업데이트 설치 차단 흐름을 수정했습니다.
- 사용자가 한 번의 탭으로 Android 시스템 설치 프로그램을 통해 계속할 수 있도록 차단된 설치 폴백을 수정했습니다.

### 개선됨
- Android 인앱 업데이트 실패에 대한 업데이트 연속성 및 복구 경로가 개선되었습니다.
