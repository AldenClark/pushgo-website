제품: PushGo

지원 이메일: [support@pushgo.dev](mailto:support@pushgo.dev)

PushGo 지원은 출시된 Apple 플랫폼 클라이언트, Android 클라이언트, Gateway 설정 질문을 다룹니다. App Store의 iOS, macOS, watchOS 버전에 대한 기술 지원 요청은 위 이메일로 보내 주세요.

## 지원을 받는 방법

알림이 오지 않거나, 구독이 실패하거나, 메시지가 동기화되지 않거나, Gateway 연결 오류 또는 예상치 못한 동작이 발생하면 [support@pushgo.dev](mailto:support@pushgo.dev)로 문의해 주세요.

## 포함하면 좋은 정보

- 기기 모델과 운영체제 버전.
- PushGo 앱 버전.
- 사용 플랫폼: iOS, macOS, watchOS, Android 또는 Gateway.
- 관련이 있다면 Gateway endpoint 또는 배포 방식.
- Channel 설정 배경. public Gateway 또는 self-hosted Gateway 사용 여부.
- 문제가 발생한 시간, 관찰한 현상, 재현 가능 여부.
- 문제 설명에 도움이 되는 스크린샷, 로그, 오류 메시지.

Channel 비밀번호, access token, private key 또는 기타 민감한 정보는 이메일로 보내지 마세요.

## 자주 묻는 질문

### 알림을 받지 못할 때 먼저 무엇을 확인해야 하나요?

먼저 시스템 알림 권한이 켜져 있는지 확인한 뒤 Gateway 주소, Channel credential, 네트워크 상태, 집중 모드, 플랫폼 push delivery 상태를 확인하세요.

### 구독 또는 메시지 동기화 문제가 있을 때 어떤 정보가 유용한가요?

사용 플랫폼, 문제가 한 기기에서만 발생하는지 여러 기기에서 발생하는지, public Gateway를 사용하는지 self-hosted Gateway를 사용하는지 알려 주세요.

### 로그를 보내야 하나요?

민감한 정보가 없는 기본 로그나 오류 메시지는 도움이 됩니다. 공유하기 전에 Channel 비밀번호, token, private key, 개인 내용을 제거해 주세요.

### 앱 업데이트는 어떻게 제공되나요?

Apple 플랫폼 업데이트는 App Store를 통해 배포됩니다. Android 릴리스와 Gateway 빌드는 각 공개 릴리스 채널을 통해 배포됩니다.

## 개인정보와 데이터

PushGo는 지원 요청을 광고나 행동 프로파일링에 사용하지 않습니다. 사용자가 지원팀에 보내는 정보는 보고한 문제를 이해하고, 진단하고, 해결하는 데만 사용됩니다.
